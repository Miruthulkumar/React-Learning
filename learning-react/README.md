# 🎓 Miruthul's Study Center

A simple React web app that displays a list of courses fetched from a JSON server.  
Each course card shows the course details, allows users to "Buy" a course, and delete it dynamically from the UI — all built using **custom React hooks**, **Axios**, and **Tailwind CSS**.

---

## 🧠 Project Overview

This project demonstrates:
- Fetching data using a **custom React hook (`useFetch`)**.
- Handling **loading** and **error states** gracefully.
- Managing **state updates** and **child-to-parent communication** (delete functionality).
- Implementing a **reusable card component** (`Courses`).
- Styling with **Tailwind CSS** for responsiveness and transitions.
- Building a clean **component-based architecture** in React.

---

## ⚙️ Features

✅ Fetch course data from a local JSON server  
✅ Sort courses by price (ascending order)  
✅ Delete individual courses from the list  
✅ Simulated "Buy Now" button with confirmation  
✅ Loading animation while fetching  
✅ Navbar with login/signup buttons
